## 摘要
我们针对具有连续状态和动作空间的网络化马尔可夫决策过程，提出了一种用于协作强化学习的连续分布式耦合策略梯度（CDCPG）算法。每个智能体在有界图邻域内维护一个局部actor，并通过局部转移核的谱随机特征表示，利用局部化最小二乘时间差分critic评估截断动作值函数。分析做出了四项贡献。首先，截断动作值函数被构造为邻域上的条件期望，从而产生了一个适定的局部化Bellman理论，消除了朴素截断论证中的延续核失配问题。其次，我们揭示了归一化随机特征在时间差分稳定性方面的维度障碍，并证明了一个无条件的激励界，该界将稳定性归结为对称的持续激励条件，可通过在线矩阵集中证书进行监控。第三，在智能体交互的指数空间衰减、激励条件以及目标光滑性的假设下，CDCPG以~O(ε^{-2})的共享oracle样本数，将每个智能体的平均平稳性度量驱动到显式表征的近似下限的任意超出量ε内，且超出量依赖性与光滑非凸一阶速率相匹配；每个智能体的计算和通信由邻域大小而非网络大小决定。第四，自适应局部性规则选择平衡截断残差和图衰减残差与目标精度的半径。在 networked 线性二次基准上的实验证实了局部性和特征维度的预测。

## Abstract
We develop the Continuous Distributed Coupled Policy Gradient (CDCPG) algorithm for cooperative reinforcement learning in networked Markov decision processes with continuous state and action spaces. Each agent maintains a local actor over a bounded graph neighborhood, and a localized least-squares temporal-difference critic evaluates a truncated action-value function through a spectral random-feature representation of the local transition kernel. The analysis makes four contributions. First, the truncated action-value function is constructed as a conditional expectation over the neighborhood, yielding a well-posed localized Bellman theory that removes the continuation-kernel mismatch of naive truncation arguments. Second, we expose a dimensional obstruction to temporal-difference stability for normalized random features and prove an unconditional excitation bound that reduces stability to a symmetric persistence-of-excitation condition, monitorable through an online matrix-concentration certificate. Third, under exponential spatial decay of agent interactions, the excitation condition, and smoothness of the objective, CDCPG drives an averaged per-agent stationarity measure to within any excess $ε$ of an explicitly characterized approximation floor using $\widetilde{\mathcal{O}}(ε^{-2})$ shared-oracle samples, and the excess dependence matches the smooth nonconvex first-order rate; per-agent computation and communication are governed by the neighborhood size rather than the network size. Fourth, an adaptive-locality rule selects the radius that balances truncation and graph-decay residuals against the target accuracy. Experiments on a networked linear-quadratic benchmark corroborate the locality and feature-dimension predictions.

### 6. 论文的主要结论与发现

1. **条件期望截断是适定的**：通过条件期望定义的截断 Q 函数配以辅助局部 Bellman 压缩算子，截断误差成为干净的结构量，克服了朴素截断的延续核失配问题。
2. **维度障碍不可避免**：TD 稳定性不存在维度无关的下界（Proposition 2 的 O(m^{-1/2}) 上界），因此分析须把特征维度 m 视为固定原语。
3. **激励即稳定**：在占有测度采样下，谱范数交叉项受 γ^{-1/2} 控制，TD 稳定性可由对称协方差的持续激励条件保证（Lemma 3），且该条件可在线监控。
4. **样本复杂度达到下界指数**：在结构下限之上，CDCPG 以 $\tilde{\mathcal{O}}(\epsilon^{-2})$ 共享 oracle 样本达到任意超出量，与光滑非凸随机一阶优化下界的指数一致（仅为指数级对比，oracle 模型不同）。
5. **结构与局部性**：每智能体的计算/通信由邻域大小而非网络规模决定；存在显式四分量结构下限（截断、RFF、图衰减、bin 内涨落）。
6. **实验验证**：在 LCQ 基准上，CDCPG 以 κ=1 的局部 critic 匹配集中式基线性能（差距 0.55% 以内），远超基于共识/注意力的分散基线；特征维数衰减斜率符合 ε_P~1/√m 预测；λ 消融与理论侧条件一致。

### 7. 优点

- **理论深度与完整性**：给出了从截断、表示、稳定性到收敛的完整闭环分析，显式刻画四分量结构下限，并对下限的维度标度做了细致讨论（Remark 3）。
- **诚实的假设管理**：将 TD 稳定性、指数衰减与微分正则性等前提分为不同假设集合（A/B/C/D），清晰区分"推导"与"后验假设"，并明确告知哪些条件可验证、哪些不能验证。
- **可监控性**：将隐性"有界逆"后设替换为矩阵 Bernstein 在线证书（Proposition 3），给出可控的误认证概率，工程可落地性强。
- **轨迹条件因果性**：Theorem 7 的可预测前缀/停时过程处理避免了对未来全局事件的条件化，确保证明在因果链路中成立。
- **κ_π=0 的精确塔消去**：Corollary 2 利用线性 critic 和塔性质证明楼内波动的精确相消，展示了对结构对称性的精细利用。
- **实验与理论对应设计**：每个实验明确对应某一理论环节，且对"未经验证/仅为代理"的部分有充分声明。

### 8. 不足与局限

- **假设强度高**：关键前提（B2 指数衰减、C/C′ TD 稳定性下界、D3 微分正则性）均为前瞻性假设，论文未提供具体连续模型类同时满足（A）、（B2）、激励界与（D3）的完整验证实例（Appendix A 仅为启发式速写）。
- **维度障碍的悲观含义**：Proposition 2 的 O(m^{-1/2}) 上界意味着特征维数增大不必然改善问题良态性，在饱和情形下（μ_M≍m^{-1/2}）通用 envelope 给出的楼内下限随 m 线性增长。论文承认这是上界分析的人工产物，但尚未给出紧的下界例证（仅有上界障碍，未见下界示例证明不可避免性）。
- **适用范围限制**：目标函数要求 n-一致的 Lipschitz 常数（依赖 D3），值函数要求全局 Qmax 界，策略类限制为有界支撑、紧参数化的指数族（有界 score），排除了无界高斯线性特征等常见情形。
- **实验覆盖有限**：单一 LCQ 基准、无高维状态/动作空间、无大规模 n 的扩展实验、无与最新实证方法（如 MAPPO、COMA）的直接对比；主实验 critic 与理论 critic 不一致使端到端验证缺位。
- **无算力报告**：未提供任何训练时长、GPU 型号等资源信息，影响可复现性和实际部署评估。
- **局部模型辅助假设（D1）较强**：每个智能体需知道 κ_c+κ 邻域内的动力学漂移函数与奖励函数，该模型辅助性质在纯黑箱环境中可能无法满足。
- **共享 oracle 的计数口径**：论文承认 eO(1/ϵ²) 为共享样本计数，并非物理上每个智能体的独立轨迹数，与标准下界比较仅限指数级，不能直接解读为完全一致的下界匹配。
