## 摘要
本文提出了一种基于Q学习的自适应信道分配框架，其中智能体通过观察网络负载、干扰条件和时间流量动态，在马尔可夫决策过程（MDP）中学习最优策略。设计了一个多目标奖励函数，以联合优化系统吞吐量、用户公平性和干扰抑制，同时采用ε-贪心策略以促进有效探索。仿真结果表明其稳定收敛，获得了37.5的平均奖励和28.5 Mbps的平均吞吐量。此外，所提方法实现了0.75的Jain公平性指数，并通过自适应响应动态流量模式，与随机分配相比，将干扰降低了26.3%。

## Abstract
This paper proposes a self-adaptive channel assignment framework based on Q-learning, where agents learn optimal policies by observing network load, interference conditions, and temporal traffic dynamics within a Markov decision process (MDP). A multi-objective reward function is designed to jointly optimize system throughput, user fairness, and interference mitigation, while an ε-greedy strategy is employed to facilitate effective exploration. Simulation results demonstrate stable convergence, achieving an average reward of 37.5 and an average throughput of 28.5 Mbps. Moreover, the proposed approach achieves a Jain's fairness index of 0.75 and reduces interference by 26.3% compared to random allocation by adaptively responding to dynamic traffic patterns.
